# 维护说明

本fork根据实际需求独立维护。此前向GitHub镜像提交的[草稿PR #58](https://github.com/teodly/inferno/pull/58)已撤回，代码和测试成果保留。

在准备向GitLab上游提交改动时，维护者遇到了额外的账户验证要求。经过反复尝试，仍未能完成全部验证，因此决定暂不通过该平台提交贡献。这次经历增加了贡献准备之外的操作成本；我们希望协作平台提供更清晰、可访问的验证流程及替代途径。以上只描述本次经历，不代表所有用户都会遇到相同情况。

This fork is maintained independently. The maintainer could not complete additional GitLab account-verification requirements despite repeated attempts, and the GitHub draft PR was withdrawn. This describes one experience, not a claim about every user. The adaptation and test results remain available in this fork.

上游主仓库：[GitLab](https://gitlab.com/lumifaza/inferno)；上游GitHub镜像：[teodly/inferno](https://github.com/teodly/inferno)。原作者文档见[归档](archive/README.md)。
